# Overview

Meld composes language-tagged regions in one source file. This book collects
the release-facing contracts and verification notes.

Read next: [Release pipeline](release.md), [Artifacts and
verification](artifacts.md), [Schemas](schemas.md), [Security](security.md).

The canonical policy files live at the repository root:

- [CHANGELOG](https://github.com/enis1enis2/meld/blob/main/CHANGELOG.md)
- [RELEASE](https://github.com/enis1enis2/meld/blob/main/RELEASE.md)
- [SEMVER](https://github.com/enis1enis2/meld/blob/main/SEMVER.md)
- [SBOM](https://github.com/enis1enis2/meld/blob/main/SBOM.md)
- [SECURITY](https://github.com/enis1enis2/meld/blob/main/SECURITY.md)
- [THIRD-PARTY-NOTICES](https://github.com/enis1enis2/meld/blob/main/THIRD-PARTY-NOTICES.md)

The first signed candidate is `v0.2.0-rc.1`. Meld follows SemVer 2.0.0. The
system package is `meld-lang`; binaries are `meld`, `meld-lsp` and `meld-pack`.
