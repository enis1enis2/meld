# Schema stability

This document records which persisted formats are contract surfaces for the
`0.2.x` line. It is intentionally explicit so release tooling can refuse
unknown or unstable schemas instead of guessing. Contract versions are shipped
under stable `vMAJOR.MINOR.PATCH` tags; the release workflow rejects pre-release
tags.

| Schema identifier | Location | Stability | Notes |
| --- | --- | --- | --- |
| `pack.toml` / Lang Pack | `packs/*/pack.toml` | stable in 0.2.x | New optional fields are minor; removing or reinterpreting a required field is major. |
| `meld-lang-library/1` | `library.toml` | stable in 0.2.x | Library manifest API version. |
| `meld-lang-library-index/1` | installed library index | stable in 0.2.x | Keyed by canonical library id. |
| `meld-project-libraries/1` | `meld.lock` | stable in 0.2.x | Project lock mapping id to exact version. |
| `meld-pack-registry/1` | `packs/registry/index.json` | stable in 0.2.x | Registry index root. |
| `meld-grammar-sources/1` | `grammar-sources.json` | stable in 0.2.x | Pinned grammar versions and verified checksums. |
| `meld-release-manifest/1` | `*.release-manifest.json` | stable in 0.2.x | Signed release manifest; versioned with the product. |
| `CycloneDX 1.6` | `*.cdx.json` | external standard | Generated by cargo-sbom; normalized metadata only. |
| `meld-value` wire tags | `spec/value-model.md` | stable in 0.2.x | `$bytes`, `$map`, `$variant`, `$some`, `$ok`, `$err`, `$handle`, `$fn`. |
| T2 job envelope | `spec/t2-protocol.md` | stable in 0.2.x | JSON envelope between scheduler and workers. |
| T3 component world | `crates/meld-t3/wit/meld.wit` | stable in 0.2.x | WIT world exported by guest components. |

## Migration rules

- Readers must reject unknown schema identifiers with an actionable error.
- Migrations are explicit tools: `tools/migrate_lock.py` and
  `tools/migrate_index.py`. They never rewrite files without `--in-place`.
- A schema identifier change requires a changelog entry and a
  [SEMVER.md](../SEMVER.md) decision.
- `tools/check_schemas.py` validates all schemas listed here before packaging.
